# 🧑 AI-Powered Intelligent Face Analyzer

## Deep Learning | Computer Vision | Facial Landmark Analysis

### 📌 About the Project

The AI-Powered Intelligent Face Analyzer is a Python-based application that uses Artificial Intelligence and Computer Vision to analyze facial images.

Users can upload an image or capture a photo using a webcam. The application detects faces, identifies facial landmarks, and displays approximate mouth-pattern classifications through an interactive Streamlit dashboard.

### ✨ Features

- Upload Image for analysis
- Live Webcam Capture
- Face Detection using OpenCV
- Facial Landmark Detection using MediaPipe
- Approximate Mouth-Pattern Estimation
- Interactive Streamlit Dashboard
- Image Analysis Results
- Detection Status Display

### 🛠️ Technologies Used

- Python
- Streamlit
- OpenCV
- MediaPipe
- NumPy
- Pillow
